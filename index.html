01 / ABOUT

研究と実装を
つなぐ。

研究アイデアを、実際に動くシステムへ。

ロボットが現場で働くためには、ロボット自身の動作だけでなく、 何を、どの順序で、どの設備や資材を使って実行するかを管理する仕組みも重要だと考えています。

現在は、自律工場に適した生産管理システムの構築をテーマに、 製造オーダーや工程、資材・設備などの情報を統合し、ロボット側の実行計画につなぐ仕組みを検討・開発しています。 また、ROS 2を用いたロボット開発にも取り組んでいます。

PythonROS 2Odoo OpenCVYOLODockerGit / GitHub
02 / RESEARCH

自律工場に適した
生産管理システムの構築

製造要求に応じて工程や作業内容を整理し、ロボット群が実行するための計画につなぐ生産管理の仕組みを目指しています。

Undergraduate Research

製造オーダーから、実行計画の一歩手前までをつなぐ

製品や製造オーダーに応じて工程を生成・選択し、資材・設備・作業場所などの情報を統合した作業リストを構成する仕組みを検討しています。

生産管理システムがロボットの動作そのものを生成するのではなく、 下位のPlannerが実行計画を生成できるよう、必要な作業情報を整理して渡すことに焦点を当てています。

※ 研究は開発・検証中です。実験結果や公開可能な図・動画は、準備ができ次第追加します。

製造オーダー製品・数量・納期など
↓
生産管理システム工程・資材・設備・作業リストの統合
↓
Plannerロボットの実行計画を生成
↓
ロボット・設備作業の実行と状態フィードバック
03 / PROJECTS

Projects & Development

研究と競技を通して取り組んできた開発テーマ。

PROJECT 01

自律工場向け生産管理システム

製造オーダーやBOM、工程・資材情報を扱い、ロボット側に渡す作業リストへつなぐ仕組みを開発。

  • Odooを用いた製造情報の管理・参照
  • PythonによるAPI連携とデータ処理
  • 生産管理層とPlannerの役割分担を設計
PROJECT 02

RoboCup @Home

家庭環境で活動するサービスロボットの競技にチームで参加。物体認識を中心に開発に取り組みました。

  • ROS 2ベースの物体認識
  • OpenCV、YOLO、Open3Dなどを活用
  • チームでの開発・タスク分担
PROJECT 03

ROS 2ロボットナビゲーション

ロボットの移動、位置推定、ナビゲーションの仕組みを理解し、実機・シミュレーション環境で検証。

  • ROS 2のTopic・Actionなどの調査
  • ナビゲーション動作とフィードバックの確認
  • ログや可視化ツールを用いた問題分析
PROJECT 04

統合システムのデモ開発

製造オーダーと、ロボット・加工設備による作業の対応関係を確認するデモ環境を構築。

  • 製造情報の入力から作業リスト作成までの連携
  • ロボット・設備の実行側との接続を検証
  • デモ映像・説明資料による成果の可視化
